【這個工具要解決什麼】
我想知道：每週一定投 BTC，如果「跌比較多時多投一點」，投入金額和平均成本會怎麼變。

【使用者要填什麼】
開始日期（預設 2022-01-03）、結束日期（預設資料最後一天 2026-09-28）、每週金額（預設 100 美元）、跌幅門檻（預設 30%）、加碼倍數（預設 2 倍）。

【規則】
1. 每週一買一次，用當週價格；只算開始到結束日期之間的週，頭尾都算。
2. 最高點＝資料中截至當週的最高價，開始日期之前的價格也要算進去。
3. 跌幅＝（最高點 − 當週價格）÷ 最高點。
4. 跌幅「超過」門檻，就投「每週金額 × 加碼倍數」；沒超過就投「每週金額」。剛好等於門檻不算超過。
5. 平均成本＝總投入 ÷ 買到的 BTC 總數。
6. 不算手續費。

【要看到什麼】
兩條規則並排：只定期定額／加碼規則。
每條都要有：總投入、買到的 BTC、平均成本、加碼次數、市值。加碼次數＝實際投入比每週金額多的週數（倍數設 1 就是 0 次）；市值用所選期間最後一筆價格算。
顯示實際算了哪幾週、共幾週；下面一張逐週明細：日期、價格、最高點、跌幅、兩條規則各投多少。
結果旁邊寫：「用當天均價回算・沒算手續費・實際不一定買得到這個價」，還有「過去結果不代表未來，也不是投資建議」。
填錯，或那段時間沒有價格資料，要提醒我，不要留著上一次的結果。

【資料】
用資料夾裡的 data/btc_weekly.csv（欄位：date, price_usd），不要上網抓。

【開啟方式】
雙擊 index.html 就能用，不用另外安裝任何東西。

【不要做】
不要下單、不要連交易所、不要給投資建議、不要說哪條規則比較好。
